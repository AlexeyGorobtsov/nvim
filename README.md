  1. Два файла рядом и переходы между ними
  :e src/app.js        открыли файл
  Пробел v             вертикальный сплит (новое окно справа, тот же файл)
  Пробел f f           в правом окне открыли другой файл через поиск
  Ctrl+h               перешли в левое окно
  Ctrl+l               вернулись в правое

  Горизонтальный сплит работает так же:
  Пробел s             окно снизу
  Ctrl+j / Ctrl+k      вниз / вверх

  Размер окон:
  Shift+→ / Shift+←    шире / уже
  Shift+↑ / Shift+↓    выше / ниже
  (Ctrl+стрелки в macOS заняты переключением рабочих столов, поэтому Shift)
  Пробел =             сделать все окна одинаковыми

  Закрыть текущее окно: :q (или Ctrl+w c).

  2. Терминал снизу

  Ctrl+\               открыть терминал внизу (первый раз создаётся новый)
  npm run dev          работаете в нём как обычно
  Ctrl+k               перешли в файл над терминалом, сервер продолжает работать
  ...редактируете код...
  Ctrl+j               вернулись в терминал
  Ctrl+q               скрыли терминал (процесс не останавливается)
  Ctrl+\               снова показали тот же терминал

  Если Ctrl+\ неудобно, то же самое делает Пробел t t.

  Терминал справа на всю высоту (код слева):
  Пробел t v           переключить терминал: снизу <-> справа
                       (если терминал открыт, он сразу переедет; иначе откроется там в следующий раз)
  Ctrl+h / Ctrl+l      переход код <-> терминал в режиме «справа»

  Совет: после Ctrl+j курсор попадает в терминал в обычном режиме. Чтобы печатать команды, нажмите i.

  3. Несколько терминалов

  Пробел t c           создать ещё один терминал (откроется в том же нижнем окне)
  Пробел t 1           переключиться на терминал 1
  Пробел t 2           на терминал 2
  ] t / [ t            следующий / предыдущий
  Пробел t l           меню со списком: Enter открыть, x закрыть, r переименовать, s отправить Ctrl+C

  Пример с фоновыми задачами из вашего конфига:
  :Task server         запустить npm run server в скрытом терминале
  :Task dev            запустить npm run dev и сразу показать его
  Пробел t l           посмотреть, что запущено

  4. Скопировать текст из терминала

  Esc Esc              выйти из режима ввода терминала
  v / y                выделить и скопировать как в обычном буфере
  i                    вернуться к вводу

  5. LSP: подсказка параметров функции

  Раньше она была на Ctrl+k, теперь это переход в окно выше. Подсказка теперь вызывается так:
  foo(|                в режиме вставки: Ctrl+k
  gK                   в обычном режиме, курсор на вызове функции

  6. Вкладки

  :tabnew              новая вкладка
  Пробел t n           следующая вкладка
  Пробел t p           предыдущая

  Встроенные gt и gT тоже работают.

  Полный список клавиш терминала: Пробел t ?. Справка по LSP: Пробел ?.
